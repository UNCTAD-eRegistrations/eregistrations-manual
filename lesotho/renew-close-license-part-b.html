1. Service Overview

The Renew or Close a Licence service allows registered business owners in Lesotho to renew or permanently terminate their trading and/or industrial licences through the OBFC online portal.

How the Service Operates

When a citizen submits this service, the system creates one or two application registrations depending on whether they are renewing, terminating, or both. All licence data is pre-loaded from the government database — the citizen does not manually enter their licence details. The process is fully automated — no officer review is required.

Fully Automated Processing

Once a citizen submits and pays, two bots run automatically. There is no officer step. If a bot fails, administrators must be able to identify the issue, retry the bot, or escalate.

2. Bot: LICENCES Update

ACTIVITIES PER BUSINESS update entries

Role ID: da643534-fbf9-4a42-a5b9-aaf5c3d68bb3  •  Short name: LICENCES update  •  Bot type: data

Automated Bot

This is the first automated step after approval. The bot updates the government Activities Per Business (APB) database with the renewed or terminated licence statuses.

What the Bot Does

Depending on the citizen's selections:

  • Renewal: Updates each renewed licence's expiry date in the database to the new expiry date calculated during the application. Sets the licence status to active/renewed.
  • Termination: Marks each terminated licence as closed/cancelled in the database, recording the termination date (today's date at time of processing).

Troubleshooting: Bot Failed

  1. 1

    Check the bot error log

    Open the application in the back-office and navigate to the LICENCES update bot step. Click the error details to see the specific failure reason.

  2. 2

    Common failure reasons

    • Licence ID not found in APB database — The licence may have been manually removed. Contact the database administrator.
    • Database connection timeout — Retry the bot; usually resolves on its own.
    • Mapping error — A field mapping may be outdated. Contact the system administrator.
  3. 3

    Retry the bot

    If the error is transient (connection issue), use the Retry action in the bot step. If the error persists after two retries, escalate to the system administrator.

3. Bot: LICENCES Upload

LICENCES upload

Role ID: f562ec66-b84a-48aa-a258-fda273052f53  •  Short name: LICENSE upload  •  Bot type: document

Automated Bot

This is the second and final automated step. After the LICENCES update bot successfully updates the database, this bot generates the updated licence certificate PDFs and uploads them to the citizen's application record for download.

What the Bot Does

  • Renewed licences: Generates a new licence certificate PDF with the updated expiry date, new start date, and renewed status. Attaches it to the application.
  • Terminated licences: Generates a termination confirmation document. Attaches it to the application.
  • Uploads all generated documents to the citizen's eRegistrations account so they can be downloaded from the portal.

The full upload workflow involves three document bots that run as part of this role:

Bot Name Purpose Bot Service
INDUSTRIAL LICENSE upload Generates industrial licence certificate PDF generic-pdf-generator
TRADING LICENSE upload Generates trading licence certificate PDF generic-pdf-generator
BUSINESS ID upload Generates updated Business ID document if required generic-pdf-generator

Bot Statuses

Troubleshooting: Bot Failed

If this bot fails, the citizen cannot download their certificate

The database has already been updated (by the previous bot). The citizen's licence is legally renewed/terminated. However, they will not be able to download their certificate until this bot succeeds. Prioritise resolution.

  • PDF template error — The template may have a formatting issue. Contact the system administrator to check the generic-pdf-generator template configuration.
  • Upload failure — The document storage service may be temporarily unavailable. Retry after 5 minutes.
  • Missing field mapping — A required field (e.g., new expiry date) may not be mapped correctly. Contact the administrator.

4. Status Reference

The following statuses are used across all desks in this service:

Status Desks Meaning
FILE PENDING Review, Approval, Both Bots Application or bot run is queued / in progress. No action required unless it stalls for more than 24 hours.
FILE VALIDATED Review, Approval, Both Bots Desk approved / bot succeeded. Application moves to the next step automatically.
SEND BACK TO CORRECTIONS Review, Approval Application returned to applicant with comments. Applicant must correct and resubmit.
FILE REJECT Review, Approval Application permanently rejected. No further processing. Applicant is notified.
Bot failed Both Bots Automated bot encountered an error. Officer must investigate and retry or escalate.

5. Troubleshooting & Support

Common Issues at Review / Approval

Issue Likely Cause Recommended Action
Applicant's licence list is empty Account not linked to business, or no licences in APB database Send back to corrections with instructions to contact OBFC help desk
Incorrect business name shown Database linkage error Reject with note; refer to database administrator
Penalty fee appears incorrect Expiry date or today's date field calculated incorrectly Manually verify using the expiry date and today's date. If the formula is wrong, send back for corrections and flag to system admin.
Citizen has selected both Renew and Close for same licence Form validation gap Send back to corrections; instruct the citizen to select only one action per licence
Payment received but application shows pending payment Payment gateway delay Wait up to 1 hour. If still pending, verify payment with the finance team and manually confirm if appropriate.
